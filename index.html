Count the shoe

Learn the Hi-Lo card counting system in short drills, from single card values to betting at a full table.

Stages

    Counting cards in your head is legal almost everywhere, including casinos, though casinos may ask you to stop playing. Using a phone, app, or any device to count at a real table is illegal in many jurisdictions. Practice here, count in your head there.

    Stage

    How Hi-Lo works

    Give every card you see a value and keep a running total, the running count. A high count means the cards left in the shoe are rich in tens and aces, which favors you.

    CardsValueWhy
    2, 3, 4, 5, 6+1Small cards leaving the shoe help you.
    7, 8, 90Neutral. Ignore them.
    10, J, Q, K, A−1Big cards leaving the shoe hurt you.

    True count

    The same running count matters more when fewer cards are left, so divide by the decks remaining.

    True count = running count ÷ decks left

    Rounding rule used here: estimate decks left to the nearest half deck, then drop the fraction toward zero. +2.6 becomes +2, and −1.7 becomes −1.

    Example: running count +9 with 3.5 decks left is 9 ÷ 3.5 = 2.57, so the true count is +2.

    Betting spread

    Bet more when the true count is high. This trainer uses a 1–8 unit spread:

    True count +1 or lower1 unit
    +22 units
    +34 units
    +46 units
    +5 or higher8 units

    A full deck

    A complete deck has twenty +1 cards and twenty −1 cards, so counting all 52 always ends at 0. That makes a full deck a perfect self-check.
